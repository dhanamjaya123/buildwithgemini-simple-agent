# My agent: GlobeTrotter AI
One-liner: A conversational travel concierge that helps travelers discover places, plan itineraries, and budget trips with a catalog of travel destinations.

Tool coverage:
- Memory: Remembers user travel preferences, budget levels, past trips, and dietary needs.
- Tools: `get_destinations`, `add_destination`, `search_destinations`.
- Catalog/UI: Destinations collection to render as interactive cards and tables.
- Image gen: Generates scenic destination visuals.
- Sandbox: Computes trip budgets and currency conversions.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for calculations
